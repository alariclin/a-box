**A-Box** یک ابزار مستقل Bash برای استقرار و نگه‌داری سرورهای لینوکسی و دروازه‌های شبکه است.

این ابزار Xray-core، sing-box، Hysteria 2 رسمی، خروجی گرفتن از پارامترهای نود، تنظیمات سیستم، محدودیت ترافیک، کنترل دسترسی، بررسی سلامت سرویس‌ها، پشتیبان‌گیری، بازیابی، عیب‌یابی و انتخاب محلی SNI را در یک اسکریپت واحد جمع می‌کند.

> فقط در محیط‌های قانونی، مجاز و منطبق با مقررات استفاده شود. مسئولیت پیامدهای عملیاتی، حقوقی و امنیتی بر عهده کاربر است.

## رعایت قوانین و سلب مسئولیت

این پروژه فقط برای **آزمایش معماری شبکه، پژوهش امنیت سایبری، خودکارسازی عملیات سیستم و حفاظت قانونی از حریم خصوصی در محیط‌های کاملاً مجاز** ارائه شده است.

1. **رعایت قانون:** از این پروژه برای هیچ فعالیتی که قوانین، مقررات، شرایط سرویس یا سیاست‌های استفاده از شبکه در کشور یا منطقه شما را نقض می‌کند استفاده نکنید.

2. **محدوده مجوز:** این پروژه را فقط روی سرورها، شبکه‌ها و سیستم‌هایی مستقر، آزمایش یا اجرا کنید که مالک آن‌ها هستید، مدیریت آن‌ها را بر عهده دارید یا برای استفاده از آن‌ها مجوز صریح دارید.

3. **مسئولیت کاربر:** کاربر به‌تنهایی مسئول تمام پیامدهای حقوقی، عملیاتی، امنیتی و انطباقی ناشی از سوءاستفاده، استفاده ممنوع، خطای پیکربندی یا اجرای نادرست است.

4. **هدف فنی:** قابلیت‌های مسیریابی، رمزنگاری، پروکسی، کنترل ترافیک و عیب‌یابی در این پروژه برای افزایش امنیت انتقال داده، دسترس‌پذیری و کارایی عملیات در محیط‌های مجاز طراحی شده‌اند. استفاده از آن‌ها برای حمله غیرقانونی، دسترسی غیرمجاز، دور زدن ممیزی، اخلال در زیرساخت یا کمک به هر فعالیت غیرقانونی ممنوع است.

5. **عدم ارائه ضمانت:** این پروژه به‌صورت «همان‌گونه که هست» ارائه می‌شود. هیچ تضمینی درباره مناسب بودن برای هدفی خاص، دسترس‌پذیری، انطباق یا بی‌خطر بودن آن در همه شبکه‌ها، سیستم‌ها یا حوزه‌های قضایی ارائه نمی‌شود.

6. **پذیرش شرایط:** با دانلود، کپی، استقرار یا اجرای این پروژه، تأیید می‌کنید که این شرایط را خوانده، درک کرده و پذیرفته‌اید.

## شروع سریع ایمن

ابتدا فایل را دانلود کنید، بررسی کنید، جمع کنترلی (checksum) بگیرید و سپس خودآزمایی (`--self-test`) را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh
sha256sum A-Box.sh
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh
```

اجرای سریع با خط لوله (pipeline) همچنان در دسترس است:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

مسیر آینه فقط زمانی استفاده شود که `raw.githubusercontent.com` در دسترس نیست:

```bash
curl -fsSL https://ghp.ci/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

انتخاب زبان رابط:

```bash
sudo bash A-Box.sh --lang zh
sudo bash A-Box.sh --lang en
```

دستورهای فقط‌خواندنی برای بررسی:

```bash
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh --status
sudo bash A-Box.sh --help
sudo bash A-Box.sh --preflight
sudo bash A-Box.sh --dry-run
```

پس از اجرای اول، منو با این دستور باز می‌شود:

```bash
sb
```

|---|---|
| استقرار | وابستگی‌ها را نصب می‌کند، محیط اجرا را آماده می‌کند و Xray-core، sing-box و Hysteria 2 رسمی را مستقر و مدیریت می‌کند. |
| مجموعه پروتکل‌ها | VLESS-Vision-Reality، VLESS-XHTTP-Reality، Shadowsocks-2022 و Hysteria 2. |
| پورت‌های پیش‌فرض | Vision `443/TCP`، XHTTP `8443/TCP`، HY2 `443/UDP`، SS-2022 `2053/TCP+UDP`؛ پورت‌های سفارشی پیش از استقرار بررسی می‌شوند. |
| سیاست SNI | SNI پیش‌فرض REALITY برابر `www.microsoft.com` است. دامنه‌های Apple/iCloud هرگز به‌عنوان مقدار داخلی پیش‌فرض استفاده نمی‌شوند. SNI شبیه Apple/iCloud روی پورت غیر `443` هشدار می‌دهد. |
| انتخاب داخلی SNI | کتابخانه محلی حالت کامل/کوچک بدون اسکریپت قدیمی راه‌دور. امتیازدهی بر اساس HTTPS/TLS، TLS 1.3، ALPN، SAN، ASN/topology انجام و نتیجه ذخیره می‌شود. |
| خروجی XHTTP | پارامترهای `/xhttp`، `stream-one`، میزبان HTTP/2 و `smux: false` را برای کلاینت‌های سازگار مانند Mihomo صادر می‌کند. |
| Hysteria 2 | ACME HTTP-01، Cloudflare DNS-01، سنجاق‌کردن گواهی خودامضا، پوشش ظاهری، پرش اختیاری پورت و مبهم‌سازی Salamander را پشتیبانی می‌کند. |
| عملیات | BBR/FQ، TCP KeepAlive، Fail2Ban، logrotate، بررسی سلامت، به‌روزرسانی Geo، قطع سرویس بر اساس سقف ماهانه، فهرست سفید برای SS-2022 و گزارش وضعیت. |
| محافظت‌های عملیاتی | پیش‌بررسی، تأیید جایگزینی استقرار، پشتیبان‌گیری پیش از عملیات پرخطر، عیب‌یابی بدون اطلاعات حساس و OTA محافظت‌شده. |
| قالب‌های خروجی | URI، QR در ترمینال، Clash/Mihomo YAML، قالب‌های خروجی برای sing-box و JSON برای v2rayN/v2rayNG. |

| `9` | پیش‌بررسی کامل بدون تغییر | بررسی غیرمخرب محیط، وابستگی‌ها، شبکه، GitHub، پورت‌ها، سرویس‌ها، دیوار آتش و فضای ذخیره‌سازی. |

## محافظت‌های نگه‌داری

- پیش از منوهای استقرار پروتکل `1` تا `10`، پیش‌بررسی سبک به‌صورت خودکار اجرا می‌شود.
- منوی `15` پیش از به‌روزرسانی هسته، بدون بازنشانی پارامترهای نود، پشتیبان خودکار می‌گیرد.
- OTA از شاخه `main` با بررسی syntax/fingerprint، نمایش SHA256 و تأیید `[Y/N]` محافظت می‌شود.
- منوهای `16` و `17` پیش از حذف یا بازنشانی محیط درباره ایجاد پشتیبان سؤال می‌کنند.
- ابزار `7` امکان پشتیبان‌گیری و بازیابی دستی را فراهم می‌کند.
- ابزار `8` بسته عیب‌یابی بدون اطلاعات حساس می‌سازد؛ UUID، کلیدهای خصوصی، گذرواژه‌ها، توکن‌ها و لینک‌های کلاینت پوشانده می‌شوند.
- ابزار `9` گزارش کامل پیش‌بررسی را در `/etc/ddr/preflight/` ذخیره می‌کند.
- ابزار `10` آخرین نتایج ذخیره‌شده حالت کامل/کوچک انتخاب SNI را نشان می‌دهد.
- اسکریپت‌های شخص ثالث در جعبه‌ابزار بخشی از A-Box نیستند. پیش از اجرا، A-Box مقدار SHA256 را نشان می‌دهد و اگر هش در `ABOX_REMOTE_SHA256_ALLOWLIST` نباشد، تأیید دقیق `YES-RUN-UNTRUSTED` لازم است.
- برای فایل‌های هسته دریافت‌شده از GitHub Releases، وجود چکیده رسمی SHA256 لازم است. به‌صورت پیش‌فرض از انتشارهای پایدار `latest` استفاده می‌شود و نسخه‌های پیش‌انتشار/alpha عمداً استفاده نمی‌شود.

## نکات انتخاب SNI

- انتخاب SNI را روی VPS اجرا کنید، نه روی لپ‌تاپ محلی؛ برای REALITY مسیر VPS به سرور هدف مهم است.
- کاندیداهای دارای `tls13=1`، `san=1`، ALPN معتبر و ASN/توپولوژی نزدیک را ترجیح دهید.
- وقتی هدف‌های عادی وب، سند یا منبع ایستای عادی با پاسخ `200` در دسترس هستند، از هدف‌های فقط API، محدودشونده، ناپایدار یا دارای پاسخ غیرطبیعی پرهیز کنید.
- از IP خام به‌عنوان SNI استفاده نکنید.
- SNI شبیه Apple/iCloud روی پورت غیر `443` به‌طور صریح توسط اسکریپت هشدار می‌دهد.
- SNI پشتیبان پیش‌فرض REALITY برابر `www.microsoft.com` است؛ دامنه‌های Apple/iCloud هرگز مقدار داخلی پیش‌فرض نیستند.
- پس از اجرای ابزار `3` یا `4`، برای دیدن نتیجه ذخیره‌شده از ابزار `10` استفاده کنید.

## پرسش‌های متداول

### اسکریپت می‌گوید TTY تعاملی در دسترس نیست.
آن را از یک ترمینال تعاملی اجرا کنید. اگر اجرای خط لوله (pipeline) شکست خورد، ابتدا فایل را دانلود کنید و سپس `sudo bash A-Box.sh` را اجرا کنید.

### استقرار به دلیل اشغال بودن پورت شکست خورد.
اسکریپت فرایندهای غیر A-Box را که پورت‌های انتخاب‌شده را گرفته‌اند بررسی می‌کند. پورت را دستی آزاد کنید یا پورت دیگری انتخاب کنید.

### آیا پیش‌بررسی نصب دوباره یک پشته موجود را متوقف می‌کند؟
خیر. پیش‌بررسی سبک فقط به این دلیل که سرویس‌های مدیریت‌شده A-Box پورت‌ها را گرفته‌اند شکست نمی‌خورد. فرایند استقرار ابتدا سرویس‌های مدیریت‌شده را متوقف می‌کند.

### پشتیبان و بسته عیب‌یابی شامل چه چیزهایی هستند؟
پشتیبان شامل پیکربندی A-Box، فایل‌های سرویس، اسکریپت‌ها، وضعیت منتخب دیوار آتش/cron و فراداده است. بسته عیب‌یابی مقادیر حساس را پنهان می‌کند.

### چرا Hysteria 2 مقدار پهنای باند بالا/پایین را می‌خواهد؟
Hysteria 2 مقدارهای `up` و `down` را به‌عنوان پارامترهای کنترل پهنای باند و کنترل ازدحام استفاده می‌کند. آن‌ها را بر اساس ظرفیت واقعی خط VPS تنظیم کنید.

### درخواست گواهی ACME شکست خورد.
در حالت HTTP-01 مطمئن شوید `80/TCP` در دسترس است و اشغال نشده است. در حالت Cloudflare DNS-01 مطمئن شوید API Token اجازه ویرایش DNS برای zone هدف را دارد.

### چگونه SNI را انتخاب کنم؟
از ابزار `3` یا `4` استفاده کنید و سپس نتایج ذخیره‌شده را با ابزار `10` ببینید. TLS 1.3، تطابق SAN، ALPN معتبر و رابطه منطقی ASN/توپولوژی با VPS را در اولویت بگذارید.
