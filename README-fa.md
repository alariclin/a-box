ابزار یک‌مرحله‌ای دروازه شبکه لینوکس.

A-Box یک اسکریپت مستقل Bash برای استقرار و نگه‌داری سرویس‌های دروازه شبکه روی لینوکس است.

این ابزار از Xray-core، sing-box، Hysteria 2 رسمی، VLESS Vision REALITY، VLESS XHTTP REALITY، Shadowsocks-2022، Hysteria 2، خروجی گرفتن از نودها، انتخاب SNI، پشتیبان‌گیری و بازیابی، مدیریت دیوار آتش، عیب‌یابی، محدودیت ترافیک، بررسی سلامت و به‌روزرسانی هسته‌ها پشتیبانی می‌کند.

> فقط در محیط‌های قانونی، مجاز و منطبق با مقررات استفاده شود. مسئولیت تمام پیامدهای حقوقی، عملیاتی و امنیتی بر عهده کاربر است.

## رعایت قوانین و سلب مسئولیت

این پروژه فقط برای آزمایش معماری شبکه، پژوهش امنیت سایبری، خودکارسازی عملیات سیستم و حفاظت قانونی از حریم خصوصی در محیط‌های کاملاً مجاز ارائه شده است.

از این پروژه برای حمله غیرقانونی، دسترسی غیرمجاز، دور زدن ممیزی، سوءاستفاده شبکه، اختلال در زیرساخت یا هر فعالیت غیرقانونی استفاده نکنید.

فقط روی سرورها، شبکه‌ها و سیستم‌هایی استفاده کنید که مالک آن‌ها هستید، آن‌ها را مدیریت می‌کنید یا برای استفاده از آن‌ها مجوز صریح دارید.

این پروژه «همان‌گونه که هست» و بدون ضمانت ارائه می‌شود. با دانلود، کپی، استقرار یا اجرای آن، این شرایط را می‌پذیرید.

## شروع سریع ایمن

روش پیشنهادی:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh
sha256sum A-Box.sh
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh
```

روش سریع با pipeline:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

مسیر آینه را فقط زمانی استفاده کنید که GitHub raw در دسترس نیست:

```bash
curl -fsSL https://ghp.ci/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

پس از نصب، منو را با این دستور باز کنید:

```bash
sb
```

انتخاب زبان:

```bash
sudo bash A-Box.sh --lang zh
sudo bash A-Box.sh --lang en
```

بررسی‌های فقط‌خواندنی:

```bash
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh --status
sudo bash A-Box.sh --help
sudo bash A-Box.sh --preflight
sudo bash A-Box.sh --dry-run
```

| نگه‌داری | از preflight، عیب‌یابی، محدودیت ترافیک، Fail2Ban، logrotate، health probe، به‌روزرسانی Geo و OTA کنترل‌شده پشتیبانی می‌کند. |

## نکات SNI

انتخاب SNI عمدتاً برای Xray REALITY و XHTTP REALITY است.

آزمون SNI را روی VPS اجرا کنید، نه روی رایانه محلی. بهترین target به مسیر شبکه از VPS تا سایت هدف بستگی دارد.

نتایجی را ترجیح دهید که `tls13=1`، `san=1`، ALPN معتبر، پاسخ HTTP عادی و رابطه منطقی ASN یا توپولوژی با VPS داشته باشند.

SNI پشتیبان داخلی REALITY:

```text
www.microsoft.com
```

دامنه‌های Apple/iCloud به‌عنوان مقدار پیش‌فرض داخلی استفاده نمی‌شوند. اگر SNI شبیه Apple/iCloud روی پورت غیر `443` استفاده شود، اسکریپت هشدار می‌دهد.

پس از اجرای ابزار `3` یا `4`، با ابزار `10` سوابق ذخیره‌شده SNI را ببینید.

## طراحی ایمنی

A-Box برای پایداری تولیدی طراحی شده است:

- UFW یا firewalld را خودکار غیرفعال نمی‌کند.
- وقتی دیوار آتش بومی فعال است، فقط پورت‌های لازم A-Box را اضافه می‌کند.
- قوانین دیوار آتش بومی ساخته‌شده توسط A-Box را برای پاک‌سازی و rollback ثبت می‌کند.
- از `killall` سراسری پرهیز می‌کند.
- پیش از توقف سرویس‌های مدیریت‌شده، مالکیت سرویس A-Box را بررسی می‌کند.
- پیش از عملیات پرخطر، از فایل‌های مهم پشتیبان می‌گیرد.
- پیکربندی‌ها، فایل‌های سرویس، باینری‌های هسته، داده‌های Xray Geo، وضعیت دیوار آتش، بلوک‌های cron و فراداده اجرا را بازیابی می‌کند.
- برای دانلود هسته‌ها و Geo، digest نوع SHA256 مربوط به GitHub Release asset را بررسی می‌کند.
- به‌صورت پیش‌فرض از انتشار پایدار `latest` استفاده می‌کند، نه نسخه‌های alpha یا prerelease.
- اسکریپت‌های شخص ثالث در جعبه‌ابزار تا زمانی که hash آن‌ها صریحاً allowlist نشده باشد، نمایش SHA256 و تأیید دقیق می‌خواهند.
- OTA از `main` به بررسی syntax/fingerprint، نمایش SHA256 و تأیید `[Y/N]` نیاز دارد. OTA غیرتعاملی به `ABOX_OTA_SHA256_ALLOWLIST` نیاز دارد.

## پرسش‌های متداول

### اسکریپت می‌گوید TTY تعاملی در دسترس نیست.
آن را از یک ترمینال تعاملی اجرا کنید. اگر حالت pipeline شکست خورد، ابتدا فایل را دانلود کنید و سپس `sudo bash A-Box.sh` را اجرا کنید.

### استقرار به دلیل اشغال بودن پورت شکست خورد.
پورت را دستی آزاد کنید یا پورت دیگری انتخاب کنید. A-Box پیش از استقرار، فرایندهای غیر A-Box را بررسی می‌کند.

### آیا preflight نصب دوباره یک A-Box موجود را متوقف می‌کند؟
خیر. preflight سبک فقط به این دلیل که سرویس‌های مدیریت‌شده A-Box پورت‌ها را گرفته‌اند شکست نمی‌خورد. هنگام استقرار، A-Box ابتدا سرویس‌های مدیریت‌شده را متوقف می‌کند و سپس مجموعه جدید را می‌نویسد.

### پشتیبان شامل چه چیزهایی است؟
پشتیبان شامل پیکربندی‌های A-Box، فایل‌های سرویس، اسکریپت‌ها، باینری‌های هسته، داده‌های Xray Geo، وضعیت دیوار آتش بومی، بلوک‌های cron مربوط به A-Box، snapshotهای iptables/ip6tables و فراداده اجرا است.

### چرا Hysteria 2 مقدار پهنای باند upload و download را می‌خواهد؟
Hysteria 2 از این مقدارها برای کنترل پهنای باند و ازدحام استفاده می‌کند. آن‌ها را مطابق ظرفیت خط VPS تنظیم کنید.

### درخواست گواهی ACME شکست خورد.
در حالت HTTP-01 مطمئن شوید `80/TCP` در دسترس است و اشغال نشده است. در حالت Cloudflare DNS-01 مطمئن شوید API token اجازه ویرایش DNS برای zone هدف را دارد.

### چگونه SNI را انتخاب کنم؟
ابزار `3` یا `4` را اجرا کنید، سپس ابزار `10` را بررسی کنید. TLS 1.3، تطابق SAN، ALPN معتبر، پاسخ HTTP عادی و رابطه منطقی ASN/توپولوژی با VPS را در اولویت بگذارید.
