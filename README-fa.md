A-Box یک اسکریپت مستقل Bash برای استقرار و نگه‌داری سرویس‌های دروازه شبکه روی لینوکس است.

این ابزار از Xray-core، sing-box، Hysteria 2 رسمی، VLESS Vision REALITY، VLESS XHTTP REALITY، Shadowsocks-2022، Hysteria 2، خروجی گرفتن از نودها، انتخاب SNI، پشتیبان‌گیری و بازیابی، مدیریت دیوار آتش، عیب‌یابی، محدودیت ترافیک، بررسی سلامت و به‌روزرسانی هسته‌ها پشتیبانی می‌کند.

> فقط در محیط‌های قانونی، مجاز و منطبق با مقررات استفاده شود. مسئولیت تمام پیامدهای حقوقی، عملیاتی و امنیتی بر عهده کاربر است.

## رعایت قوانین و سلب مسئولیت

این پروژه فقط برای آزمایش معماری شبکه، پژوهش امنیت سایبری، خودکارسازی عملیات سیستم و حفاظت قانونی از حریم خصوصی در محیط‌های کاملاً مجاز ارائه شده است.

از این پروژه برای حمله غیرقانونی، دسترسی غیرمجاز، دور زدن ممیزی، سوءاستفاده شبکه، اختلال در زیرساخت یا هر فعالیت غیرقانونی استفاده نکنید.

فقط روی سرورها، شبکه‌ها و سیستم‌هایی استفاده کنید که مالک آن‌ها هستید، آن‌ها را مدیریت می‌کنید یا برای استفاده از آن‌ها مجوز صریح دارید.

این پروژه «همان‌گونه که هست» و بدون ضمانت ارائه می‌شود. با دانلود، کپی، استقرار یا اجرای آن، این شرایط را می‌پذیرید.

## شروع سریع امن

### منبع رسمی جهانی

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

### آینه پشتیبان برای شبکه‌های با دسترسی دشوار یا ناپایدار (سرویس شخص ثالث)

```bash
curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

فقط زمانی از این آینه شخص ثالث استفاده کنید که منبع رسمی GitHub در دسترس نیست یا اتصال ناپایدار است. در حالت عادی منبع رسمی جهانی را ترجیح دهید. پس از نصب، برای باز کردن منو `sb` را اجرا کنید.

## قابلیت‌های اصلی

| بخش | عملکرد |
|---|---|
| استقرار هسته‌ها | Xray-core، sing-box و Hysteria 2 رسمی |
| پروتکل‌ها | VLESS Vision REALITY، VLESS XHTTP REALITY، Shadowsocks-2022 و Hysteria 2 |
| خروجی نود | URI، کد QR، Clash/Mihomo YAML، sing-box outbound و JSON برای v2rayN/v2rayNG |
| ابزارهای شبکه | آزمون SNI، کیفیت IP و مسیر، WARP و بهینه‌سازی VPS |
| نگه‌داری | بررسی سلامت، محدودیت ترافیک، Fail2Ban، logrotate، Geo و ارتقای هسته‌ها |
| ایمنی | بررسی مالکیت سرویس، بازگردانی دیوار آتش، تراکنش استقرار و OTA کنترل‌شده |
| بازیابی | پشتیبان‌گیری، بازیابی، تبدیل پشتیبان قدیمی و بسته عیب‌یابی |

## روش استفاده

| فرمان | عملکرد |
|---|---|
| `sb` | باز کردن منوی اصلی پس از نصب |
| `sudo bash A-Box.sh --self-test` | اجرای بررسی‌های داخلی |
| `sudo bash A-Box.sh --preflight` | بررسی سرور پیش از استقرار |
| `sudo bash A-Box.sh --status` | نمایش پیکربندی و وضعیت سرویس‌ها |
| `sudo bash A-Box.sh --start` | راه‌اندازی سرویس‌های مدیریت‌شده |
| `sudo bash A-Box.sh --stop` | توقف سرویس‌های مدیریت‌شده |
| `sudo bash A-Box.sh --version` | نمایش نسخه ساخت |

## روش پیشنهادی استفاده

| سناریو | گزینه پیشنهادی |
|---|---|
| استقرار متعادل | منوی `5`: Xray + HY2 رسمی |
| VPS کم‌حافظه | منوی `10`: مجموعه کامل sing-box |
| اتصال اصلی TCP | منوی `1`: Xray VLESS Vision REALITY |
| جایگزین TCP با توان بالا | منوی `2`: Xray VLESS XHTTP REALITY |
| شبکه موبایل یا ناپایدار | منوی `4`: Hysteria 2 رسمی |
| نود relay یا landing | منوی `3`: Xray Shadowsocks-2022 با فهرست سفید |

برای محیط عملیاتی ابتدا `--self-test` و `--preflight` را اجرا کنید، کلید بازیابی پشتیبان را جداگانه نگه دارید و GitHub Release دارای برچسب ثابت را به شاخه بدون نسخه ثابت ترجیح دهید.
