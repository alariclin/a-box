A-Box یک اسکریپت مستقل Bash برای راه‌اندازی و نگه‌داری سرویس‌های دروازه شبکه در لینوکس است.

این ابزار از Xray-core، sing-box، سرور رسمی Hysteria 2، VLESS Vision REALITY، VLESS XHTTP REALITY، Shadowsocks-2022، خروجی پیکربندی کلاینت، آزمون SNI، پشتیبان‌گیری و بازیابی، مدیریت دیوار آتش، عیب‌یابی، محدودیت ترافیک، بررسی سلامت و به‌روزرسانی اجزای اصلی پشتیبانی می‌کند.

> فقط در محیط‌های قانونی، مجاز و منطبق با مقررات از این پروژه استفاده کنید. مسئولیت تمام پیامدهای حقوقی، عملیاتی و امنیتی بر عهده کاربر است.

## رعایت قوانین و سلب مسئولیت

این پروژه فقط برای آزمایش معماری شبکه، پژوهش امنیت سایبری، خودکارسازی مدیریت سیستم و حفاظت قانونی از حریم خصوصی در محیط‌های کاملاً مجاز ارائه شده است.

از این پروژه برای حمله غیرقانونی، دسترسی غیرمجاز، دور زدن ممیزی، سوءاستفاده از شبکه، اختلال در زیرساخت یا هر فعالیت غیرقانونی دیگری استفاده نکنید.

فقط روی سرورها، شبکه‌ها و سیستم‌هایی از آن استفاده کنید که مالک یا مدیر آن‌ها هستید، یا برای استفاده از آن‌ها مجوز صریح دارید.

این پروژه «همان‌گونه که هست» و بدون ضمانت ارائه می‌شود. با دانلود، کپی، راه‌اندازی یا اجرای آن، این شرایط را می‌پذیرید.

## شروع سریع امن

### منبع رسمی GitHub

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

### آینه جایگزین برای دسترسی محدود یا ناپایدار به GitHub (سرویس شخص ثالث)

```bash
curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

فقط زمانی از آینه شخص ثالث استفاده کنید که منبع رسمی GitHub در دسترس نیست یا اتصال به آن ناپایدار است. در حالت عادی منبع رسمی را ترجیح دهید. پس از نصب، برای باز کردن منو فرمان `sb` را اجرا کنید.

## قابلیت‌های اصلی

| بخش | عملکرد |
|---|---|
| راه‌اندازی سرویس‌ها | Xray-core، sing-box و سرور رسمی Hysteria 2 |
| پروتکل‌ها | VLESS Vision REALITY، VLESS XHTTP REALITY، Shadowsocks-2022 و Hysteria 2 |
| خروجی پیکربندی | URI، کد QR، Clash/Mihomo YAML، الگوهای outbound برای sing-box و JSON برای v2rayN/v2rayNG |
| ابزارهای شبکه | آزمون SNI، بررسی کیفیت IP و مسیر، مدیریت WARP و بهینه‌سازی VPS |
| نگه‌داری | بررسی سلامت، محدودیت ترافیک، Fail2Ban، logrotate، به‌روزرسانی Geo و اجزای اصلی |
| ایمنی | بررسی مالکیت سرویس‌های مدیریت‌شده، بازگردانی قوانین دیوار آتش، تراکنش راه‌اندازی و OTA محافظت‌شده |
| بازیابی | پشتیبان‌گیری و بازیابی، تبدیل پشتیبان‌های قدیمی و بسته عیب‌یابی بدون اطلاعات حساس |

## روش استفاده

| فرمان | عملکرد |
|---|---|
| `sb` | باز کردن منوی اصلی پس از نصب |
| `sudo bash A-Box.sh --self-test` | اجرای بررسی‌های داخلی |
| `sudo bash A-Box.sh --preflight` | بررسی سرور پیش از راه‌اندازی |
| `sudo bash A-Box.sh --status` | نمایش پیکربندی و وضعیت سرویس‌ها |
| `sudo bash A-Box.sh --start` | راه‌اندازی سرویس‌های مدیریت‌شده |
| `sudo bash A-Box.sh --stop` | توقف سرویس‌های مدیریت‌شده |
| `sudo bash A-Box.sh --version` | نمایش نسخه ساخت |

## نیازمندی‌های سیستم

| مورد | نیازمندی |
|---|---|
| سیستم‌عامل | Debian 10+، Ubuntu 20.04+، CentOS/RHEL/Rocky/AlmaLinux 8+ یا Alpine Linux |
| سامانه راه‌اندازی (`init`) | systemd یا OpenRC |
| معماری پردازنده | amd64/x86_64 یا arm64/aarch64 |
| دسترسی | root یا sudo |
| شبکه | دسترسی به مخازن بسته‌های سیستم و GitHub Releases |
| وابستگی‌ها | بسته‌های ضروری در صورت نبود، به‌صورت خودکار نصب می‌شوند |
| زبان رابط اسکریپت | انگلیسی یا چینی ساده‌شده |

## روش پیشنهادی استفاده

| سناریو | گزینه پیشنهادی |
|---|---|
| پیکربندی متعادل | منوی `5`: بسته Xray + Hysteria 2 رسمی |
| VPS با حافظه کم | منوی `10`: بسته sing-box |
| اتصال اصلی TCP | منوی `1`: Xray VLESS Vision REALITY |
| جایگزین TCP با توان بالا | منوی `2`: Xray VLESS XHTTP REALITY |
| شبکه موبایل یا ناپایدار | منوی `4`: Hysteria 2 رسمی |
| نود واسط یا خروجی | منوی `3`: Xray Shadowsocks-2022 با فهرست مجاز |

برای محیط تولید، ابتدا `--self-test` و `--preflight` را اجرا کنید، کلید بازیابی نسخه پشتیبان را جداگانه نگه دارید و انتشار GitHub با برچسب نسخه ثابت را به شاخه‌ای متغیر مانند `main` ترجیح دهید.

مستندات به زبان‌های انگلیسی، چینی ساده‌شده، روسی و فارسی در دسترس است. رابط تعاملی اسکریپت فقط به زبان‌های انگلیسی و چینی ساده‌شده ارائه می‌شود.
