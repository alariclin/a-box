Набор инструментов для сетевого шлюза Linux с установкой одной командой.

A-Box — автономный Bash-скрипт для развёртывания и обслуживания сетевых шлюзов на Linux.

Он поддерживает Xray-core, sing-box, официальный сервер Hysteria 2, VLESS Vision REALITY, VLESS XHTTP REALITY, Shadowsocks-2022, экспорт клиентских конфигураций, тестирование SNI, резервное копирование и восстановление, управление брандмауэром, диагностику, ограничения трафика, проверки работоспособности и обновление серверных компонентов.

> Используйте проект только в законных, разрешённых и соответствующих требованиям средах. Пользователь несёт ответственность за все правовые, эксплуатационные и связанные с безопасностью последствия.

## Правовые условия и отказ от гарантий

Проект предназначен только для тестирования сетевой архитектуры, исследований в области кибербезопасности, автоматизации системного администрирования и законной защиты конфиденциальности в полностью авторизованных средах.

Не используйте его для незаконных атак, несанкционированного доступа, обхода аудита, злоупотребления сетью, нарушения работы инфраструктуры или иной противоправной деятельности.

Используйте проект только на серверах, в сетях и системах, которыми вы владеете, управляете или для которых получили явное разрешение.

Проект предоставляется «как есть», без каких-либо гарантий. Скачивая, копируя, развёртывая или запуская его, вы принимаете эти условия.

## Безопасный быстрый старт

### Официальный источник GitHub

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

### Резервное зеркало при ограниченном или нестабильном доступе к GitHub (сторонний сервис)

```bash
curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

Используйте стороннее зеркало только тогда, когда официальный источник GitHub недоступен или работает нестабильно. По возможности используйте официальный источник. После установки выполните `sb`, чтобы открыть меню.

## Основные функции

| Раздел | Функция |
|---|---|
| Развёртывание сервисов | Xray-core, sing-box и официальный сервер Hysteria 2 |
| Протоколы | VLESS Vision REALITY, VLESS XHTTP REALITY, Shadowsocks-2022 и Hysteria 2 |
| Экспорт конфигураций | URI, QR-код, Clash/Mihomo YAML, шаблоны исходящих подключений sing-box и JSON для v2rayN/v2rayNG |
| Сетевые инструменты | Тестирование SNI, проверка качества IP и маршрута, управление WARP и оптимизация VPS |
| Обслуживание | Проверки работоспособности, ограничения трафика, Fail2Ban, logrotate, обновления Geo и серверных компонентов |
| Безопасность | Проверка принадлежности управляемых сервисов, откат правил брандмауэра, транзакции развёртывания и защищённое OTA-обновление |
| Восстановление | Резервное копирование и восстановление, преобразование старых архивов и диагностические пакеты без конфиденциальных данных |

## Использование

| Команда | Функция |
|---|---|
| `sb` | Открыть главное меню после установки |
| `sudo bash A-Box.sh --self-test` | Запустить встроенные проверки |
| `sudo bash A-Box.sh --preflight` | Проверить сервер перед развёртыванием |
| `sudo bash A-Box.sh --status` | Показать конфигурацию и состояние сервисов |
| `sudo bash A-Box.sh --start` | Запустить управляемые сервисы |
| `sudo bash A-Box.sh --stop` | Остановить управляемые сервисы |
| `sudo bash A-Box.sh --version` | Показать версию сборки |

## Системные требования

| Пункт | Требование |
|---|---|
| ОС | Debian 10+, Ubuntu 20.04+, CentOS/RHEL/Rocky/AlmaLinux 8+ или Alpine Linux |
| Система инициализации | systemd или OpenRC |
| Архитектура процессора | amd64/x86_64 или arm64/aarch64 |
| Права | root или sudo |
| Сеть | Доступ к системным репозиториям пакетов и GitHub Releases |
| Зависимости | Отсутствующие обязательные пакеты устанавливаются автоматически |
| Интерфейс скрипта | Английский или упрощённый китайский |

## Рекомендуемое использование

| Сценарий | Рекомендуемый вариант |
|---|---|
| Сбалансированная конфигурация | Меню `5`: пакет Xray + официальный сервер Hysteria 2 |
| VPS с малым объёмом памяти | Меню `10`: пакет sing-box |
| Основное TCP-соединение | Меню `1`: Xray VLESS Vision REALITY |
| Высокопроизводительная TCP-альтернатива | Меню `2`: Xray VLESS XHTTP REALITY |
| Мобильная или нестабильная сеть | Меню `4`: официальный сервер Hysteria 2 |
| Ретрансляционный или выходной узел | Меню `3`: Xray Shadowsocks-2022 со списком разрешённых адресов |

Для производственной системы сначала выполните `--self-test` и `--preflight`, храните ключ восстановления резервной копии отдельно и предпочитайте GitHub Release с фиксированным тегом, а не изменяемую ветвь, например `main`.

Документация доступна на английском, упрощённом китайском, русском и персидском языках. Интерактивный интерфейс скрипта доступен на английском и упрощённом китайском языках.
