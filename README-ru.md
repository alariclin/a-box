**A-Box** — автономный Bash-инструмент для развёртывания и сопровождения Linux-серверов и сетевых шлюзов.

Он объединяет Xray-core, sing-box, официальную Hysteria 2, экспорт параметров узлов, системную настройку, лимиты трафика, контроль доступа, проверки состояния, резервное копирование, восстановление, диагностику и локальный подбор SNI.

## Безопасный быстрый старт

Сначала скачайте файл, проверьте его и выполните встроенный самотест:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh
sha256sum A-Box.sh
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh
```

Быстрый запуск через конвейер также доступен:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

Зеркальный канал используйте только тогда, когда `raw.githubusercontent.com` недоступен:

```bash
curl -fsSL https://ghp.ci/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

Выбор языка интерфейса:

```bash
sudo bash A-Box.sh --lang zh
sudo bash A-Box.sh --lang en
```

Команды только для проверки:

```bash
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh --status
sudo bash A-Box.sh --help
sudo bash A-Box.sh --preflight
sudo bash A-Box.sh --dry-run
```

После первого запуска меню открывается командой:

```bash
sb
```

## Основные возможности

| Раздел | Описание |
|---|---|
| Развёртывание | Устанавливает зависимости, готовит окружение, развёртывает и управляет Xray-core, sing-box и официальной Hysteria 2. |
| Набор протоколов | VLESS-Vision-Reality, VLESS-XHTTP-Reality, Shadowsocks-2022 и Hysteria 2. |
| Порты по умолчанию | Vision `443/TCP`, XHTTP `8443/TCP`, HY2 `443/UDP`, SS-2022 `2053/TCP+UDP`; пользовательские порты проверяются перед развёртыванием. |
| Политика SNI | SNI по умолчанию для REALITY — `www.microsoft.com`. Домены Apple/iCloud никогда не используются как встроенное значение по умолчанию. SNI, похожий на Apple/iCloud, на портах не `443` вызывает предупреждение. |
| Встроенный подбор SNI | Локальная библиотека полного/малого режима без старого удалённого SNI-скрипта. Оценка учитывает HTTPS/TLS, TLS 1.3, ALPN, SAN, ASN/топологию и сохраняет результаты. |
| Экспорт XHTTP | Экспортирует `/xhttp`, `stream-one`, HTTP/2-хост и `smux: false` для совместимых клиентов, например Mihomo. |
| Hysteria 2 | Поддерживает ACME HTTP-01, Cloudflare DNS-01, закрепление самоподписанного сертификата, маскировку, дополнительную скачкообразную смену портов и обфускацию Salamander. |
| Эксплуатация | BBR/FQ, TCP KeepAlive, Fail2Ban, logrotate, проверка состояния, обновление Geo, месячный лимит трафика, белый список для SS-2022 и отчёт о состоянии. |
| Защита операций | Предварительные проверки, подтверждение замены развёртывания, резервная копия перед рискованными действиями, обезличенная диагностика и защищённое OTA-обновление. |
| Форматы экспорта | URI, QR в терминале, Clash/Mihomo YAML, шаблоны исходящих подключений sing-box и JSON для v2rayN/v2rayNG. |

## Полное меню

| Номер | Функция | Назначение |
|---:|---|---|
| `1` | Xray VLESS-Vision-Reality | Основной TCP-путь REALITY + Vision. |
| `2` | Xray VLESS-XHTTP-Reality | XHTTP поверх REALITY для совместимых настольных клиентов. |
| `3` | Xray Shadowsocks-2022 | Вход TCP/UDP для ретрансляции или конечного узла; рекомендуется белый список. |
| `4` | Официальная Hysteria 2 | UDP/QUIC/H3 для мобильных или нестабильных сетей. |
| `5` | Xray + официальная HY2, полный набор | Vision + XHTTP + HY2 + SS-2022. |
| `6` | sing-box VLESS-Vision-Reality | Развёртывание Vision для серверов с малым объёмом памяти. |
| `7` | sing-box Shadowsocks-2022 | Лёгкое развёртывание SS-2022. |
| `8` | sing-box VLESS + SS-2022 | Лёгкая схема с двумя протоколами. |
| `9` | sing-box Hysteria 2 | HY2, реализованная через sing-box. |
| `10` | sing-box, полный набор | Vision + HY2 + SS-2022; XHTTP намеренно не включён. |
| `11` | Инструменты | Тест производительности, качество IP, подбор SNI, WARP, файл подкачки, резервное копирование, восстановление, диагностика, предварительная проверка и записи SNI. |
| `12` | Оптимизация VPS | BBR/FQ, лимиты файлов, KeepAlive, Fail2Ban и проверка состояния. |
| `13` | Показать параметры узлов | Ссылки, QR-коды, YAML, JSON и шаблоны исходящих подключений. |
| `14` | Руководство | Полное руководство в терминале. |
| `15` | OTA, Geo и обновление ядер | Обновление скрипта A-Box, данных Xray Geo или установленных ядер без сброса параметров узлов. |
| `16` | Полное удаление | Удаляет управляемые службы, конфигурации, правила межсетевого экрана и необязательный ярлык `sb`. |
| `17` | Удаление узлов и сброс окружения | Удаляет остаточные процессы, старые правила и повреждённые конфигурации/службы. |
| `18` | Месячный лимит трафика | Лимит на основе vnStat; после достижения лимита службы останавливаются. |
| `19` | Управление белым списком SS-2022 | Добавляет/удаляет IP/CIDR фронтенда и применяет DROP для источников вне белого списка. При возврате в режим белого списка сначала удаляются старые общие ACCEPT-правила. |
| `20` | Настройка языка | Переключает китайский/английский интерфейс и сохраняет выбор в `/etc/ddr/.lang`. |
| `0` | Выход | Выход из меню. |

## Инструменты

| Номер | Функция | Описание |
|---:|---|---|
| `1` | Тест производительности системы | Запускает `bench.sh` для проверки оборудования и скорости загрузки. |
| `2` | Проверка качества IP и маршрута | Запускает Check.Place для проверки качества IP, потоковых сервисов и маршрута. |
| `3` | Локальный полный подбор SNI | Использует полную встроенную библиотеку кандидатов с повышенной параллельностью и глубокой проверкой. |
| `4` | Подбор SNI для слабых серверов | Использует ту же библиотеку кандидатов, но снижает параллельность и глубину проверки. |
| `5` | Управление Cloudflare WARP | Загружает сторонний WARP-скрипт; A-Box показывает SHA256 и требует строгого подтверждения перед запуском. |
| `6` | Создание файла подкачки 2 ГБ | Создаёт `/swapfile`, чтобы снизить риск нехватки памяти на серверах с малым объёмом памяти. |
| `7` | Резервное копирование / восстановление | Создаёт или восстанавливает резервные копии конфигурации A-Box. |
| `8` | Обезличенный диагностический пакет | Экспортирует состояние, порты, версии, журналы, фрагменты межсетевого экрана, cron и очищенные данные окружения. |
| `9` | Полная предварительная проверка без изменений | Неразрушающе проверяет окружение, зависимости, сеть, GitHub, порты, службы, межсетевой экран и хранилище. |
| `10` | Сохранённые результаты подбора SNI | Показывает сохранённые результаты полного/малого режима из `/etc/ddr/A-Box-sni-full.tsv` и `/etc/ddr/A-Box-sni-mini.tsv`. |

## Защитные механизмы обслуживания

- Лёгкая предварительная проверка автоматически запускается перед меню развёртывания протоколов `1`-`10`.
- Меню `15` создаёт автоматическую резервную копию перед обновлением ядра без сброса параметров узлов.
- OTA из ветки `main` защищено проверкой синтаксиса/текстового отпечатка, показом SHA256 и подтверждением `[Y/N]`.
- Меню `16` и `17` спрашивают о создании резервной копии перед удалением или сбросом окружения.
- Инструмент `7` предоставляет ручное резервное копирование и восстановление.
- Инструмент `8` создаёт обезличенный диагностический пакет; UUID, закрытые ключи, пароли, токены и клиентские ссылки маскируются.
- Инструмент `9` сохраняет полный отчёт предварительной проверки в `/etc/ddr/preflight/`.
- Инструмент `10` показывает последние сохранённые результаты полного/малого режима подбора SNI.
- Сторонние скрипты в инструментах не являются частью A-Box. Перед запуском A-Box показывает SHA256 и требует точное подтверждение `YES-RUN-UNTRUSTED`, если хеш не указан в `ABOX_REMOTE_SHA256_ALLOWLIST`.
- Для файлов ядра из GitHub Releases требуется официальный SHA256-дайджест. По умолчанию используются стабильные релизы `latest`; предварительные/alpha-версии намеренно не используются.

## Рекомендованные схемы развёртывания

| Сценарий | Рекомендуемый вариант |
|---|---|
| Сбалансированное производственное развёртывание | Меню `5`: Xray + официальная HY2, полный набор. |
| Сервер с малым объёмом памяти | Меню `10`: полный набор sing-box. |
| Основной TCP-путь | Меню `1`: Xray VLESS-Vision-Reality (`443/TCP`). |
| Быстрый настольный резервный путь | Меню `2`: Xray VLESS-XHTTP-Reality (`8443/TCP`). |
| Мобильная или нестабильная сеть | Меню `4`: официальная Hysteria 2 (`443/UDP`). |
| Ретрансляционный или конечный узел | Меню `3`: Xray SS-2022 (`2053/TCP+UDP`) + белый список. |

## Заметки по выбору SNI

- Запускайте подбор SNI на VPS, а не на локальном ноутбуке: для REALITY важен путь от VPS к целевому серверу.
- Предпочитайте кандидатов с `tls13=1`, `san=1`, корректным ALPN и близкой ASN/топологией, если она доступна.
- Избегайте предназначенных только для API, нестабильных, ограничиваемых по частоте или необычно отвечающих целей, когда доступны обычные веб-, документные или статические цели с ответом `200`.
- Не используйте необработанный IP-адрес как SNI.
- SNI, похожий на Apple/iCloud, на портах не `443` явно предупреждается скриптом.
- Резервный SNI по умолчанию для REALITY — `www.microsoft.com`; домены Apple/iCloud никогда не используются как встроенное значение по умолчанию.
- Используйте инструмент `10`, чтобы просмотреть сохранённый результат после инструмента `3` или `4`.

## Частые вопросы

### Скрипт сообщает, что нет интерактивного TTY.
Запускайте его из интерактивного терминала. Если конвейерный запуск не работает, сначала скачайте файл и выполните `sudo bash A-Box.sh`.

### Развёртывание остановилось из-за занятого порта.
Скрипт проверяет процессы вне A-Box, занимающие выбранные порты. Освободите порт вручную или выберите другой.

### Предварительная проверка мешает переустановке уже развёрнутого набора?
Нет. Лёгкая предварительная проверка не завершится ошибкой только потому, что управляемые A-Box службы уже занимают порты. Само развёртывание сначала останавливает управляемые службы.

### Что входит в резервные копии и диагностику?
Резервные копии содержат конфигурацию A-Box, файлы служб, скрипты, выбранные состояния межсетевого экрана/cron и метаданные. Диагностика маскирует чувствительные значения.

### Почему Hysteria 2 запрашивает входящую/исходящую пропускную способность?
Hysteria 2 использует заданные значения `up` и `down` как параметры управления полосой пропускания и перегрузкой. Указывайте их по фактической пропускной способности линии VPS.

### Не удалось получить ACME-сертификат.
Для HTTP-01 убедитесь, что `80/TCP` доступен и не занят. Для Cloudflare DNS-01 убедитесь, что API Token имеет право редактировать DNS-записи нужной зоны.

### Как выбирать SNI?
Используйте инструмент `3` или `4`, затем просмотрите сохранённые результаты через инструмент `10`. Предпочитайте TLS 1.3, совпадение SAN, корректный ALPN и разумную связь ASN/топологии с VPS.
