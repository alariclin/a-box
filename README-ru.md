A-Box — автономный Bash-скрипт для развёртывания и сопровождения сетевых шлюзов Linux.

Он поддерживает Xray-core, sing-box, официальную Hysteria 2, VLESS Vision REALITY, VLESS XHTTP REALITY, Shadowsocks-2022, Hysteria 2, экспорт узлов, подбор SNI, резервное копирование и восстановление, работу с межсетевым экраном, диагностику, лимиты трафика, проверки состояния и обновление ядер.

> Используйте проект только в законной, авторизованной и соответствующей правилам среде. Пользователь отвечает за все правовые, эксплуатационные и безопасностные последствия.

## Соответствие требованиям и отказ от ответственности

Проект предназначен только для тестирования сетевой архитектуры, исследований кибербезопасности, автоматизации системного администрирования и законной защиты приватности в полностью авторизованных средах.

Не используйте проект для незаконных атак, несанкционированного доступа, обхода аудита, сетевых злоупотреблений, нарушения работы инфраструктуры или любой противоправной деятельности.

Используйте его только на серверах, в сетях и системах, которыми вы владеете, управляете или для которых получили явное разрешение.

Проект предоставляется «как есть», без каких-либо гарантий. Скачивая, копируя, разворачивая или запуская его, вы принимаете эти условия.

## Безопасный быстрый старт

Рекомендуемый способ:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh
sha256sum A-Box.sh
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh
```

Быстрый запуск через конвейер:

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

Резервное зеркало используйте только тогда, когда GitHub raw недоступен:

```bash
curl -fsSL https://ghp.ci/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh | sudo bash
```

После установки откройте меню командой:

```bash
sb
```

Выбор языка:

```bash
sudo bash A-Box.sh --lang zh
sudo bash A-Box.sh --lang en
```

Проверки только для чтения:

```bash
sudo bash A-Box.sh --self-test
sudo bash A-Box.sh --status
sudo bash A-Box.sh --help
sudo bash A-Box.sh --preflight
sudo bash A-Box.sh --dry-run
```

## Основные возможности

| Раздел | Что делает |
|---|---|
| Развёртывание | Устанавливает зависимости и разворачивает Xray-core, sing-box или официальную Hysteria 2. |
| Протоколы | VLESS Vision REALITY, VLESS XHTTP REALITY, Shadowsocks-2022 и Hysteria 2. |
| Порты по умолчанию | Vision `443/TCP`, XHTTP `8443/TCP`, HY2 `443/UDP`, SS-2022 `2053/TCP+UDP`. |
| SNI radar | Встроенная библиотека из 4096 кандидатов SNI для выбора цели REALITY/XHTTP. |
| Экспорт | URI, QR-код, Clash/Mihomo YAML, шаблоны исходящих подключений sing-box и JSON для v2rayN/v2rayNG. |
| Безопасность межсетевого экрана | Не отключает UFW или firewalld автоматически. Отслеживает правила, созданные A-Box, для очистки и отката. |
| Безопасность служб | Избегает глобального `killall` и проверяет принадлежность службы A-Box перед остановкой управляемых служб. |
| Восстановление | Создаёт и восстанавливает резервные копии конфигураций, service-файлов, бинарных файлов ядер, данных Xray Geo, состояния межсетевого экрана, блоков cron и runtime-метаданных. |
| Обслуживание | Поддерживает предварительные проверки, диагностику, лимиты трафика, Fail2Ban, logrotate, health probe, обновления Geo и защищённое OTA. |

## Заметки по SNI

Подбор SNI в основном предназначен для Xray REALITY и XHTTP REALITY.

Запускайте проверку SNI на VPS, а не на локальном компьютере. Лучший target зависит от сетевого пути от VPS до целевого сайта.

Предпочитайте результаты с `tls13=1`, `san=1`, корректным ALPN, нормальным HTTP-ответом и разумной связью ASN или топологии с VPS.

Встроенный резервный SNI для REALITY:

```text
www.microsoft.com
```

Домены Apple/iCloud не используются как встроенные значения по умолчанию. Скрипт предупреждает, если SNI, похожий на Apple/iCloud, используется на порту не `443`.

После запуска инструмента `3` или `4` используйте инструмент `10`, чтобы посмотреть сохранённые записи SNI.

## Модель безопасности

A-Box ориентирован на стабильную production-эксплуатацию:

- Не отключает UFW или firewalld автоматически.
- Если активен штатный межсетевой экран, добавляет только нужные порты A-Box.
- Отслеживает созданные A-Box правила штатного межсетевого экрана для очистки и отката.
- Избегает глобального `killall`.
- Проверяет принадлежность службы A-Box перед остановкой управляемых служб.
- Создаёт резервные копии важных файлов перед рискованными операциями.
- Восстанавливает конфигурации, service-файлы, бинарные файлы ядер, данные Xray Geo, состояние межсетевого экрана, блоки cron и runtime-метаданные.
- Проверяет SHA256 digest GitHub Release asset для загрузок ядер и Geo-данных.
- По умолчанию использует стабильные latest-релизы, а не alpha или prerelease-сборки.
- Сторонние toolbox-скрипты требуют показа SHA256 и точного подтверждения, если их хеш явно не добавлен в allowlist.
- OTA из `main` требует проверки синтаксиса/отпечатка, показа SHA256 и подтверждения `[Y/N]`. Неинтерактивное OTA требует `ABOX_OTA_SHA256_ALLOWLIST`.

## Частые вопросы

### Скрипт сообщает, что интерактивный TTY недоступен.
Запустите его из интерактивного терминала. Если pipeline-режим не работает, сначала скачайте скрипт и выполните `sudo bash A-Box.sh`.

### Развёртывание не удалось из-за занятого порта.
Освободите порт вручную или выберите другой порт. A-Box проверяет процессы вне A-Box перед развёртыванием.

### Предварительная проверка заблокирует переустановку существующего A-Box?
Нет. Лёгкая предварительная проверка не падает только из-за того, что управляемые A-Box службы уже занимают порты. При развёртывании A-Box сначала останавливает управляемые службы и затем записывает новый набор.

### Что входит в резервную копию?
Резервные копии включают конфигурации A-Box, service-файлы, скрипты, бинарные файлы ядер, данные Xray Geo, состояние штатного межсетевого экрана, блоки cron A-Box, выбранное состояние firewall и runtime-метаданные.

### Почему Hysteria 2 запрашивает upload и download bandwidth?
Hysteria 2 использует эти значения для управления пропускной способностью и перегрузкой. Указывайте их по фактической пропускной способности линии VPS.

### Не удалось получить ACME-сертификат.
Для HTTP-01 убедитесь, что `80/TCP` доступен и не занят. Для Cloudflare DNS-01 убедитесь, что API token имеет право редактировать DNS-записи нужной зоны.

### Как выбрать SNI?
Запустите инструмент `3` или `4`, затем проверьте инструмент `10`. Предпочитайте TLS 1.3, совпадение SAN, корректный ALPN, нормальный HTTP-ответ и разумную ASN/топологическую связь с VPS.
