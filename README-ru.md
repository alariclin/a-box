A-Box — автономный Bash-скрипт для развёртывания и сопровождения сетевых шлюзов Linux.

Он поддерживает Xray-core, sing-box, официальную Hysteria 2, VLESS Vision REALITY, VLESS XHTTP REALITY, Shadowsocks-2022, Hysteria 2, экспорт узлов, подбор SNI, резервное копирование и восстановление, работу с межсетевым экраном, диагностику, лимиты трафика, проверки состояния и обновление ядер.

> Используйте проект только в законной, авторизованной и соответствующей правилам среде. Пользователь отвечает за все правовые, эксплуатационные и безопасностные последствия.

## Соответствие требованиям и отказ от ответственности

Проект предназначен только для тестирования сетевой архитектуры, исследований кибербезопасности, автоматизации системного администрирования и законной защиты приватности в полностью авторизованных средах.

Не используйте проект для незаконных атак, несанкционированного доступа, обхода аудита, сетевых злоупотреблений, нарушения работы инфраструктуры или любой противоправной деятельности.

Используйте его только на серверах, в сетях и системах, которыми вы владеете, управляете или для которых получили явное разрешение.

Проект предоставляется «как есть», без каких-либо гарантий. Скачивая, копируя, разворачивая или запуская его, вы принимаете эти условия.

## Безопасный быстрый старт

### Официальный глобальный источник

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

### Резервное зеркало для сетей с затруднённым или нестабильным доступом (сторонний сервис)

```bash
curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/alariclin/a-box/main/install.sh -o A-Box.sh && sudo bash A-Box.sh
```

Используйте это стороннее зеркало только тогда, когда официальный источник GitHub недоступен или работает нестабильно. По возможности выбирайте официальный глобальный источник. После установки выполните `sb`, чтобы открыть меню.

## Основные функции

| Раздел | Функция |
|---|---|
| Развёртывание ядер | Xray-core, sing-box и официальная Hysteria 2 |
| Протоколы | VLESS Vision REALITY, VLESS XHTTP REALITY, Shadowsocks-2022 и Hysteria 2 |
| Экспорт узлов | URI, QR-код, Clash/Mihomo YAML, sing-box outbound и JSON для v2rayN/v2rayNG |
| Сетевые инструменты | Проверка SNI, качества IP и маршрута, WARP и оптимизация VPS |
| Обслуживание | Проверка состояния, лимиты трафика, Fail2Ban, logrotate, Geo и обновление ядер |
| Безопасность | Проверка принадлежности служб, откат firewall, транзакции развёртывания и контролируемый OTA |
| Восстановление | Резервное копирование, восстановление, преобразование старых архивов и диагностические пакеты |

## Использование

| Команда | Функция |
|---|---|
| `sb` | Открыть главное меню после установки |
| `sudo bash A-Box.sh --self-test` | Запустить встроенные проверки |
| `sudo bash A-Box.sh --preflight` | Проверить сервер перед развёртыванием |
| `sudo bash A-Box.sh --status` | Показать конфигурацию и состояние служб |
| `sudo bash A-Box.sh --start` | Запустить управляемый набор служб |
| `sudo bash A-Box.sh --stop` | Остановить управляемый набор служб |
| `sudo bash A-Box.sh --version` | Показать версию сборки |

| Пункт | Требование |
|---|---|

| Система инициализации | systemd или OpenRC |
| Архитектура | amd64/x86_64 или arm64/aarch64 |
| Права | root или sudo |
| Сеть | Доступ к системным репозиториям и GitHub Releases |
| Зависимости | Отсутствующие обязательные пакеты устанавливаются автоматически |

## Рекомендуемое использование

| Сценарий | Рекомендуемый вариант |
|---|---|
| Сбалансированное развёртывание | Меню `5`: Xray + официальная HY2 |
| VPS с малым объёмом памяти | Меню `10`: полный набор sing-box |
| Основное TCP-соединение | Меню `1`: Xray VLESS Vision REALITY |
| Высокопроизводительный TCP-резерв | Меню `2`: Xray VLESS XHTTP REALITY |
| Мобильная или нестабильная сеть | Меню `4`: официальная Hysteria 2 |
| Relay или landing node | Меню `3`: Xray Shadowsocks-2022 с белым списком |

Для рабочего сервера сначала выполните `--self-test` и `--preflight`, храните ключ восстановления резервной копии отдельно и предпочитайте GitHub Release с фиксированным тегом.
